# Personal Website – Alexander Hempel

This is the source code for my personal website: [hempeleconomics.com](https://hempeleconomics.com).  
The site is built with [Hugo](https://gohugo.io/) using the [Hugo Academic (Wowchemy) theme](https://wowchemy.com/).

## About Me
I am a PhD economist and visiting scholar with research interests in urban economics, housing markets, and environmental policy.  
You can learn more about my work and publications on the website.

## Features
- Academic profile and research portfolio
- CV download
- Responsive design for all devices
